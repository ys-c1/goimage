# 曝光补偿拼接

`img` 包新增曝光补偿拼接接口，原有 API（`New`、`SavePGM`、`LoadPGM`、`Quantize`、
`LevelsUsed`）未改动。原有的直通拼接保留为 `StitchDirect`，逐位行为不变。

```go
func StitchDirect(a, b *Gray, overlap int) (*Gray, error)                  // 原有直通拼接
func FitExposure(a, b *Gray, overlap int) (*ExposureFit, error)           // 只求解，不出图
func StitchExposure(a, b *Gray, overlap int) (*Gray, *ExposureFit, error) // 补偿后拼接
```

两图横向拼接，`overlap` 为重叠列数：图 1 的末 `overlap` 列与图 2 的前
`overlap` 列对应同一组场景点。输出画幅 `a.W+b.W-overlap × a.H`。

## 模型与方程

对重叠区的每一对同一场景点 `(a_i, b_i)` 写线性响应

```
g1·a_i + c1 = g2·b_i + c2        i = 1..n
```

四个未知量只有两个独立约束方向：等式两边同乘一个常数、或同加一个常数都
成立，因此必须固定规范。取图 1 为基准 `(g1,c1)=(1,0)`，剩余未知量是图 2 的
增益 `g` 与偏置 `c`，问题化为超定最小二乘

```
min  Σ (g·b_i + c − a_i)²
```

中心化后闭式解

```
g = Σ(b_i−b̄)(a_i−ā) / Σ(b_i−b̄)²
c = ā − g·b̄
```

摘要中的 `ResidualBefore/After` 是重叠区平均绝对亮度差，按最终 8 位输出
（含四舍五入）计算。

## 样本筛选

只用**两侧都严格落在 (0,255) 内**的重叠样本参与拟合。0 和 255 是传感器在
补偿前就已截断的值，不满足线性曝光关系；把它们纳入最小二乘会把增益拉向
0 或无穷。饱和样本另行计数（`Usable` / `Saturated`）并保留一份“全部样本”
残差作对照，但两条核验都只用可用样本。

## 两条核验（分开验，互不掺入）

- **核验一**：`ResidualAfter × 10 ≤ ResidualBefore`。补偿前残差为零时要求
  补偿后也为零。只看重叠区。
- **核验二**：图 2 的**非重叠区**（独有列）补偿后必须全部落在 `[0,255]`，
  即 `NonOverlapClip == 0`。与核验一的统计域完全不重叠。

`StitchExposure` 落位时：

1. 图 1 原样落位；
2. 图 2 独有区按 `g·I+c` 四舍五入落位（越界会计入 `NonOverlapClip`，不会
   被静默吞掉）；
3. 重叠区取图 2 的补偿值；若图 2 该像素已落在 0/255 而图 1 仍有效，则改用
   图 1 的原始值（`FallbackToBase` 计数），避免最终输出残留饱和块。无饱和
   时回退数为 0，落位与直通拼接逐位一致。

`ResidualAfter` 是所有可用样本上的纯模型残差；`ResidualAfterPlaced` 按上面的
实际落位策略统计重叠区最终残差（饱和点回退图 1 后差值为 0）。在局部过曝用例
中前者为 0.2404、后者为 0.1953，可见回退不掩盖拟合质量，只把已被截断的样本
排除在成品误差之外。

## 欠定时的正则项

当重叠区没有对比度（纯色）时 `Σ(b−b̄)² = 0`，增益不可辨识，普通最小二乘
退化为 `0/0`。此时改用 Tikhonov 正则

```
min  Σ (g·b_i + c − a_i)² + λ·(g−1)²,     λ = 1e-6·(Σ b_i² + n)
```

选择理由：

- **只惩罚增益、不惩罚偏置。** 平坦区里均值差由数据唯一确定（`c = ā − g·b̄`
  随 `g` 连续变化但始终让均值对齐），没有信息的是对比度，因此正则只该作用
  在 `g` 上。
- **惩罚中心取 `g = 1`。** “不改变对比度”是唯一不引入任意尺度的先验；取 0
  或其它值等于凭空把图 2 的纹理压暗或放大一个固定倍数。
- **强度相对数据自适应。** `λ` 与 `Σb²` 同量级缩放，使 `λ/(Σ(b−b̄)²)` 约等于
  `1e-6·(1 + (b̄²+1)/σ²)`。纹理明显（σ 大）时正则项相对法方程可忽略，解与
  普通最小二乘的差异不足一个码值；只在 σ→0 时接管，把 `g` 稳定在 1，由偏置
  吸收均值差。

实际数值：纯色用例重叠区恒为 102/204，`λ = 21.3079`，解得 `g = 1.000000`、
`c = −102.0000`，残差 `102 → 0`。

## 拒绝路径

所有拒绝都返回 `*FigureError`，`Error()` 里带 `图 1` / `图 2` / `图 1|2`，
可用 `errors.Is` 匹配哨兵错误、`errors.As` 取出图号。

| 输入 | 图号 | 哨兵错误 |
|---|---|---|
| `overlap == 0` | `图 1|2` | `ErrOverlapEmpty` |
| `overlap < 0` 或超过较窄一图宽度 | `图 1|2` | `ErrOverlapRange` |
| 两图高度不一致 | `图 1|2` | `ErrHeightMismatch` |
| `nil`、宽/高 ≤ 0、`len(Pix) < W*H` | `图 1` 或 `图 2` | `ErrEmptyImage` |
| 拟合出的增益 `g < 0` | `图 2` | `ErrNegativeGain` |
| 重叠区全部落在 0/255，无可用样本 | `图 1|2` | `ErrNoUsable` |

## 核验与报告

五组用例（同曝光、差一档、差三档、局部过曝、纯色）见
`internal/testimg/exposure.go`；测试与报告命令共用这份定义，避免漂移。

`go test ./img -run 'TestExposure|TestStitch' -v` 覆盖：

- 五组用例的增益是否符合已知曝光比（1、1/2、1/8），基准图是否恒等；
- 核验一：残差至少缩小 10 倍（独立断言）；
- 核验二：非重叠区零截断（独立断言）；
- 三种拒绝路径都报出正确图号；
- 直通拼接与输入逐位一致，画幅固定为 112×32；
- 补偿拼接中局部过曝的 96 个饱和像素全部回退到图 1。

`artifacts/exposure-report.md` 由 `go run ./cmd/exposurereport` 生成，表 1 把
增益、偏置、残差三列并列。
