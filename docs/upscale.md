# 边缘导向放大

`img` 包新增三种放大接口，原有 API（`New`、`SavePGM`、`LoadPGM`、`Quantize`、
`LevelsUsed`）未改动。

```go
func UpscaleNearest(g *Gray, scale float64) (*Gray, error)      // 基线：最近邻
func UpscaleBicubic(g *Gray, scale float64) (*Gray, error)      // 基线：双三次
func UpscaleEdgeDirected(g *Gray, scale float64) (*Gray, error) // 边缘导向
```

三个接口签名一致、都接受任意 `scale >= 1`；整数倍率与小数倍率均可。
倍率为 1 时三种实现都逐像素返回输入。

## 算法

对每个输出像素：

1. **解出方向**。在源图上用 Sobel 求梯度，外积成结构张量
   `J = [[Jxx,Jxy],[Jxy,Jyy]]`，再以高斯核（半径 2、σ=1）平滑。
   对每个目标点双线性采样 `J`，求其主特征向量得到边缘法向 `n`，
   切向 `t = (-n_y, n_x)`；主次特征值之比给出相干度
   `coherence = (λ1-λ2)/(λ1+λ2) ∈ [0,1]`。
2. **沿边缘方向插值**。在目标点沿 `t` 取四个采样点
   （−1.5、−0.5、+0.5、+1.5 个源像素），用 Keys 三次核（a=−0.5）加权，
   避免跨边混合造成发虚。相干度低时按 `1-coherence` 向双三次混合：
   各向同性纹理没有可靠方向，强行沿切向采样反而丢细节。
3. **垂直方向限幅锐化**。沿 `n` 在 ±1 源像素处取双线性均值，对插值结果做
   `val = base + 3·coherence·(base − mean)`。
4. **零过冲**。最后把 `val` 钳到该目标点双线性插值实际触及的源像素值域
   `[min,max]`（见 `footprintRange`）。由于钳制上界本身就是源数据在该点的
   局部极值，结果不可能越过源值域——过冲幅度严格为零，而非“很小”。

相干度为 0 时（纯色区域）既无方向也无锐化，等价于双三次。

## 错误契约

越界或空输入逐项拒绝，错误信息以字段名开头，`FieldError` 提供 `FieldName()`
与 `Unwrap()`，可用 `errors.Is` 匹配哨兵错误：

| 输入 | 字段名 | 哨兵错误 | 说明 |
|---|---|---|---|
| `scale < 1`、`NaN`、`Inf` | `scale` | `ErrScale` | 倍率为 1 合法；小于 1 属缩小，不在本接口范围 |
| `nil`、宽/高 ≤ 0、`len(Pix) < W*H` | `image` | `ErrEmptyImage` | |
| 整图梯度恒为零（纯色输入） | `gradient` | `ErrGradientZero` | 无方向可解，边缘导向拒绝；两基线照常放大 |

## 核验

`go test ./img` 逐项检查：

- **相似度**：五类用例（直边、斜边、细线、纹理、纯色）× 两档倍率（2×、4×），
  要求边缘导向 SSIM **严格高于**双三次。
- **过冲**：同一批用例，要求两种判据下过冲都为零——
  源图局部 3×3 值域（较宽、独立于实现），以及实现限幅所用的 2×2
  双线性足迹（最严格）。
- **基线**：确认最近邻/双三次对纯色照常放大，并确认双三次确实产生过冲
  （判据未失灵）。
- **接口**：最近邻倍率 1 恒等、整数倍率块复制；三种实现倍率 1 恒等。

《`artifacts/upscale-report.md`》由 `go run ./cmd/upscalereport` 生成，
给出相似度对照、过冲统计（按档）、差值与耗时。
