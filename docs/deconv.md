# 迭代反卷积：边界白边的消除

单次锐化把边缘两侧的灰度拉开，边缘旁边留下一条越过局部值域的白边
（暗侧更暗、亮侧更亮），看起来像描了一圈轮廓。本接口按**已知模糊核**做
迭代反卷积：每轮更新后施加非负与总和约束，并用随迭代收缩的局部值域预算
把白边压回去。

原有单次锐化保持不变。

```go
func SharpenUnsharp(g *Gray, k Kernel, amount float64) (*Gray, error) // 原有单次锐化
func Deconvolve(g *Gray, opt DeconvOptions) (*Gray, *DeconvStats, error)
func GaussianKernel(size int, sigma float64) (Kernel, error)
func NewKernel(w []float64, size int) (Kernel, error)
func (k Kernel) Blur(g *Gray) (*Gray, error)
```

`SharpenUnsharp` 的公式冻结为 `x = g + amount·(g − K·g)`（钳到 `[0,255]`
后四舍五入），与反卷积初值逐位一致，`img/deconv_test.go` 用固定输入锁定了
它的输出。

## 算法

迭代取 Van Cittert / Landweber 形式，核已归一化，故 `‖K‖₂ = max|H| = 1`：

```
x ← x + Kᵀ(g − Kx)
```

`Kᵀ` 是 `K` 的**精确**转置，边界也不例外。正变换取重复边界，越界邻点的
权重并入边缘像素，映射在边界上多对一；此时转置不能把核镜像后照样 clamp，
那只是相关运算，`⟨Kx,y⟩ ≠ ⟨x,Kᵀy⟩`（非对称核误差可达数级）。转置改为反向
散射：正变换里读入某像素的权重加到哪里，转置就把贡献加回同一位置。
`TestKernelAdjoint` 用非对称核与 1×N 小画幅核验 `⟨Kx,y⟩ = ⟨x,Kᵀy⟩`。

每轮之后依次施加三个约束：

1. **非负**：`x ← max(x, 0)`。
2. **总和**：整体平移使 `Σx = Σg`。求解 `min‖x−y‖² s.t. Σx=S, L≤x≤U`，
   KKT 解为 `x = clip(y+t, L, U)`，`t` 由二分唯一确定。
3. **振铃预算**（默认开启）：把每个像素钳到观测图 3×3 局部值域向外扩
   `Budget` 的盒内；`Budget` 取上一轮实测振铃幅度的 `1/2`。
   因此振铃幅度每轮至少减半，且 `Budget < 0.5` 时归零。停机那轮再以
   `Budget = 0` 投影一次，结果严格落在值域内。

初值取单次锐化结果（`Amount` 为锐化量）；`Amount = 0` 时直接从观测图起步。
只有这一条路径不做振铃压制，用于对照。

## 两条核验（分开验，互不掺入）

振铃判据：输出相对**观测图** 3×3 局部值域的最大越界灰度级。

- **核验一**：每次迭代的振铃幅度单调不增，且终值不超过半级（0.5）。
- **核验二**：最终过冲像素数为零（越界超过半级的像素个数）。

两者在 `TestDeconvRingingDecreases` 与 `TestDeconvFinalOvershootZero` 中
各自独立断言。停机的那一轮会再做一次预算为零的投影，把结果落回局部值域
内部；这一步只会减小过冲，把“终值不超过半级”从观测结论变成构造保证
（半级恰在 8 位量化的进位边界上，若停在 0.5 会舍入成一级）。

## 停止准则：为什么不能只看残差

停机要求**残差与振铃同时**满足下界：

1. 残差 ≤ 残差下界，即 `‖Kx−g‖ ≤ ‖Kg−g‖`——至少比不反卷积拟合得更好；
2. 振铃幅度 ≤ 半级。

Landweber 是半收敛的：迭代会压低数据残差，同时放大被核压掉的频段，
白边随之出现。实测（见 `artifacts/deconv-report.md` 第 3 节）：

- 单次锐化初值的残差已低于下界（阶跃 0.0061 < 0.0136），但振铃 10.75 级；
  只按残差停机，收下的正是带白边的那张图。
- 关闭振铃预算后残差从 0.00498 一路降到 0.00282（下界 0.0136），
  振铃却从 12.8 级涨到 15.1 级。

两条下界同时在场才能既避免欠迭代（残差停在平凡解），又避免过迭代（白边）。

## 错误契约

越界或空输入逐项拒绝，错误信息以字段名开头；`FieldError` 提供
`FieldName()` 与 `Unwrap()`，可用 `errors.Is` 匹配哨兵错误：

| 输入 | 字段名 | 哨兵错误 | 说明 |
|---|---|---|---|
| `nil`、宽/高 ≤ 0、`len(Pix) < W*H` | `image` | `ErrEmptyImage` | |
| `MaxIter ≤ 0` | `maxIter` | `ErrIterations` | |
| `Amount` 为负、NaN、Inf | `amount` | `ErrAmount` | 取 0 合法，表示不平滑起步 |
| 核频域符号有零点 | `kernel` | `ErrKernelSingular` | 见下 |
| 核长为偶数或非正 | `kernel.size` | `ErrKernel` | 无中心无法对齐 |
| 核元素个数不符、和不为正 | `kernel` | `ErrKernel` | |
| 核含负权重、NaN、Inf | `kernel[i]` | `ErrKernel` | 带首个非法元素下标 |

可逆性判据：归一化核的频率响应 `|H(ω)|` 的最小/最大比低于 `1e-6`。
先在 64×64 频率网格上扫描，再对最低的 16 个格点做二维黄金分割细化——
只采网格会漏掉落在格点之间的零点：3×3 方框核的零点在 `(π/2, π/2)`，
网格上 `|H|` 仍有 `3.6e-4`，会骗过阈值。细化后 3×3 / 5×5 方框核与
`(1,2,1)⊗(1,2,1)` 核均判为不可逆。3×3 高斯的一维符号在 Nyquist 处为
`2e^(−1/2σ²) − 1`，`σ > 1/√(2·ln2) ≈ 0.8493` 时变号——频率响应穿过零点，
同样判为不可逆；实测 `σ=0.84` 接受、`σ=0.85` 拒绝。5×5 高斯在
`σ=1.2` 起被拒。

`SharpenUnsharp` 只要求结构合法的核：非锐化掩膜用方框核是常见做法，
可逆性仅是反卷积路径的专属条件。

## 用例

五幅合成图（128×128），每幅用已知核模糊后作为观测输入：
阶跃、细线、棋盘、噪点（固定种子 LCG）、纯色。定义在
`img/deconv_cases.go`，测试与报表共用，避免漂移。

## 核验与报告

```
go test ./img -run 'TestDeconv|TestKernel|TestSharpen' -v
go run ./cmd/deconvreport
```

报表 `artifacts/deconv-report.md` 给出五幅用例的迭代次数、残差（初值 /
下界 / 终值）、振铃幅度与振铃像素的逐轮轨迹、单次锐化与反卷积的过冲对比、
以及关闭预算的对照。
